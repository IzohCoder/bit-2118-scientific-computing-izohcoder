# BIT 2118 Scientific Computing

Individual practical work for the BIT 2118 assignment. This repository covers Tasks 2–20 from the official assignment PDF, preserves the PDF's example inputs in reproducible programs, changes at least one input for each task, and implements a related practical case for each topic.

## Start here

Requirements: Python 3.10 or newer, NumPy, SciPy, and Matplotlib.

From the repository folder, install dependencies and run a task:

```powershell
python -m pip install -r requirements.txt
python code\Task_10_bisection_fixed_point.py
```

Run all 19 tasks and save their console output and figures:

```powershell
python code\run_all.py
```

Plots are saved under `results/figures/`. Each program can also be run directly; it writes any relevant figure automatically. Outputs and benchmark times can vary slightly with the installed libraries and computer.

## Project map

- `code/Task_*.py` — one launchable file for each task.
- `code/runner.py` — shared implementations, original examples, parameter changes, and related real-world cases.
- `docs/TECHNICAL_REPORT.md` — methods, actual results, interpretations, assumptions, and limitations.
- `docs/REQUIREMENTS_CHECKLIST.md` — assignment requirement tracking.
- `results/runs/` — captured output from the verified run.
- `results/figures/` — plots generated by the programs.
- `FINAL_SUBMISSION_GUIDE.md` — handover, study notes, and VLMS checklist.
- `BIT_2118_Scientific_Computing Group Work.pdf` — the supplied source assignment.

The full requirements and final handover are in `FINAL_SUBMISSION_GUIDE.md`. Student-specific information remains as a placeholder until supplied.
